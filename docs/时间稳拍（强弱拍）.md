# 时间稳拍（强弱拍）

界面上叫「右手稳拍（强弱拍）」（2026-11-26 改名，原名时间稳拍（强弱拍）；代码、设置字段仍用原来的名字）。

这套排法由 Linxi-1105 设计（分支 codex/time-strong-weak-v1.3.5，基于 1.3.5），先照原样搬进来作为试验性排法。6K、8K 是在他的 4K 上展开的：每一下的手照 4K，同一只手连着按的快连打用更多手指（见 docs/开发说明.md 排键规则第 15 条）。下面的数据是他在 1.3.5 上量的。

在游戏中打开 **F8 → 排键 → 排法 → 右手稳拍（强弱拍）**。以下键名按右手为惯用手、开启轮指且外侧手指先按举例。选择左手为惯用手时，键位左右镜像。

## 哪只手接下一拍

- 先用现有规则把砖分成击打时刻，识别单押与多押。决定用哪只手时，依据是各次击打的时间和按键数。轨道朝向和估算的小节线都不参与分手。
- 慢速等距单点倾向让右手食指连续敲。双押正好落在这个脉冲上时，右手可以用 `J+K` 承接。felys 的 6.167 秒就是这样的落点。
- 密集单点倾向左右交替。局部已经建立均匀的细分时，把空过去的时间也算进去。例如连续间隔是 75、150、75 毫秒，依次跨 1、2、1 格，倾向换手、同手、换手。这样右手可以一直点原来的拍，左手补在中间。
- 遇到反复出现的附点节奏，尝试用同一时间单位解释整段。例如 300 和 450 毫秒分别占 2 格和 3 格。两种间隔反复出现才采纳这个解释，随后连同前后能接上的单点一起定起手。连续乐句从两端一起算，长度可以超过 16 个音。
- 高速短轮指同时看进串和出串。三下填入主拍之间，下一下又回到原有脉冲时，可以排成 `K J F → J`。允许审核中可打的短回指。长按、三押和四押附近沿用基础排法处理占键与松键。

## 六份审核稿的逐拍核对

使用主手重置间隔 100 毫秒、同键间隔参数 150 毫秒、右手惯用、外侧手指先按。按起止砖号对齐，一次击打的全部键位相同才计一次命中；一个双押计一次。六首均参与了规则提炼。

| 谱面 | 击打时刻 | 标准时间重置命中 | 时间稳拍（强弱拍）命中 |

| felys | 1,064 | 758 | 1,023 |
| Sinkhole | 1,621 | 331 | 1,572 |
| Avantgarde | 968 | 794 | 921 |

其中有些片段允许多种手法。例如 Avantgarde 标注两种排法都可的慢段，连续右手与保存的左右交替仍会按不同键位计入差异。
