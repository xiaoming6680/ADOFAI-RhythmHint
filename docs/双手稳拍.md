# 双手稳拍

界面上叫「按拍分手」（2026-11-26 改名，原名双手稳拍；代码、设置字段仍用原来的名字）。

这套排法由 Linxi-1105 设计（分支 codex/steady-six-v1.3.5，基于 1.3.5），先照原样搬进来作为试验性排法。6K、8K 是在他的 4K 上展开的：每一下的手照 4K，同一只手连着按的快连打用更多手指（见 docs/开发说明.md 排键规则第 15 条）。下面的数据是他在 1.3.5 上量的。在游戏中打开 F8 → 排键 → 排法 → 按拍分手。手序编辑器的参考面板可以显示并应用这套手序。已有设置继续控制惯用手、轮指和多押用手。

## 排键规则

- 先用拍位、相邻节奏和入砖方向选择左右手。快速等距的单双押混排把每个双押当成一个节奏位置，整体交替。极快短轮指根据接拍选择收尾，持续快串使用四指循环。
- 慢速重复图形中，若以主手带入且已有至少三分之二的音在同一只手上，优先把零星换手并回主手。
- 加速的衔接段让主手先打完较宽的接拍，进入密集分拍后再交替。已有交替起手的三连音延续交替到尾音，下一拍再接回起手。
- 谱面原生的多次按键砖按游戏设置保留所需按键数。用多个普通砖写出的疑似多押只有两砖时才归为双押，三个以上的普通砖保留各自时刻。

| 排法 | 与审核稿逐键一致 |
| --- | ---: |
| 1.3.5 正式版标准 | 6,495 / 9,613 |
| 1.3.5 正式版交替优先 | 7,479 / 9,613 |

## Heaven’s Gateway 复核

本轮用 Heaven’s Gateway、felys、Sinkhole、Avantgarde [Lightweight Ver.]、Higher 和 CE-TX Dramatic Entrance! 的六份审核稿回放。

- 第 595–660 砖形状多变，击打间隔持续在约 179 毫秒。扩大可识别的重复图形长度后，整段按审核稿交给右手 J。
- 约 2:02 的连续双押即使没有夹单押，也按实际等距击打交替。拍线有漂移时，这段仍保持同一套左右顺序。
- 约 2:05 的四指轮指接双押，双押交给刚腾出的一手。后面的直线持续在同一拍格内减速，保留交替直至相邻间隔达到 150 毫秒，再由主手接回单点。
- 强拍上的短两音收尾如果之后留有足够空拍，按同手轮指收住。弱拍上的同形片段依然可用两手。

Heaven’s Gateway 从 1,255 / 1,317 提升到 1,317 / 1,317。其余五份审核的自动输出逐音一致。以编辑器的 150 毫秒窗口计算，Heaven’s Gateway 减少了 69 对同键提醒，同时在两次轮指接双押的地方按审核稿保留了 4 对约 134 毫秒的回指。

## 120 毫秒单手间隔试验

双手稳拍生成完整键序后，沿击打时间检查左右手最近按过的键。单押和同手双押可以整体换手，同手双押算一次击打。检查覆盖隔着另一手击打的回指，长按开始的键位和需要双手同时处理的音符保持原有分配。超过两手处理能力时，先减少 120 毫秒内的同键重复，再减少同手短间隔，最后尽量保留原有手序。

未审核的 Machinegun Psystyle 会话中，120 毫秒内的同键重复从 10 处降至 0，同手短间隔从 369 处降至 347。Heaven’s Gateway 仍与审核稿逐键一致。Sinkhole 的部分高速轮指改成交替或调整了起手，逐键吻合减少 452 个。
